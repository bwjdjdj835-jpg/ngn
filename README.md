# Legado Barbearia — site

Site de uma página (React + Vite + Tailwind): hero com a foto real, serviços com filtro,
**agendador que monta a mensagem pronta no WhatsApp**, galeria com lightbox, FAQ e mapa.

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # gera /dist
```

Dados do negócio (nome, telefone, WhatsApp, serviços, FAQ): `src/dados.json`.
Fotos: `public/fotos/`. Publicação automática no GitHub Pages: `.github/workflows/deploy.yml`.
